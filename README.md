# homebrew-tap

Homebrew casks maintained by [orangesago](https://github.com/orangesago).

## Install

```bash
brew install --cask orangesago/tap/comux
brew install --cask orangesago/tap/handytab
brew install --cask orangesago/tap/sago-drop
```

## Casks

- [Comux](https://github.com/orangesago/comux) — Codex account limits in the macOS menu bar.
- [HandyTab](https://github.com/orangesago/handy-tab) — Open a favorite browser tab with a hand wave or trackpad tap.
- [Sago Drop](https://github.com/orangesago/sago-drop) — Upload files from the macOS menu bar.
